# Marca de NeumorStudio

El logo es el **NS**: una N y una S en un solo trazo, con un hueco arriba y otro abajo en la N. No se rediseña sin el acuerdo de Stark y Carlos.

## Archivos

Todo está en `public/marca/`.

| Archivo | Para qué |
| --- | --- |
| `ns-marca.svg` | El maestro. Toma el color del texto (`currentColor`) |
| `ns-marca-blanco.svg` | Sobre fondo oscuro. Es la versión principal |
| `ns-marca-negro.svg` | Sobre fondo claro |
| `ns-marca-ambar.svg` | Acento, nunca como logo principal |
| `ns-icono-oscuro.svg` | Icono de app, favicon y avatar de redes |
| `ns-icono-ambar.svg` | Variante de icono para campañas |
| `icono-*.png` | Exportados en 16, 32, 48, 180, 192, 512 y 1024 px |

El render 3D (`public/images/logoneumor.jpeg`) es una imagen de marca, no el logo. Sirve para portadas, anuncios y tiendas. Por debajo de unos 200 px se usa siempre el plano.

## Colores

| Nombre | Valor | Uso |
| --- | --- | --- |
| Negro | `#0B0B0F` | Fondo principal |
| Blanco | `#FFFFFF` | Logo y texto |
| Ámbar | `#F2A93B` | Único acento |

## Reglas

- El tema oscuro es la cara de la marca: web, anuncios y tiendas.
- No se deforma, no se gira y no se le añaden sombras al logo plano.
- Tamaño mínimo: 16 px en pantalla.
